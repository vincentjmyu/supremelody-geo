# 光量生物科技 發佈測試：GitHub Pages 渠道

這篇是光量生物科技（supremelody.com.tw）GeoLook 看板的發佈渠道連線測試，確認「內容工作臺 → GitHub 倉庫 → Pages 公開網頁」整條路能通。

## 為什麼要有一個公開落點

AI 搜尋引擎要引用一個企業或一段說明，前提是它有一個公開、穩定、可被抓取的頁面。GitHub Pages 讓我們不必另外架站，就能把文章變成可被引用的來源網址。

## 這篇的用途

- 驗證 token 權限、API 寫入與 Pages 自動部署
- 之後正式內容會放在同一目錄 `articles/`
